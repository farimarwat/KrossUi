# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 2.x | ✅ |
| 1.x | ❌ |

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/farimarwat/KrossUi/security/advisories/new)
with steps to reproduce. You'll get a reply as soon as possible, and a fix release if the report is confirmed.
